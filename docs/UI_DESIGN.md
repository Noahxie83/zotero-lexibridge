# 界面设计与验证

## 设计判断

面向论文阅读者的轻量本地词典，采用克制的阅读界面、蓝色强调色与原生 CSS。
使用用户指定的 `design-taste-frontend` 技能，参数为设计变化 4、动效强度 2、视觉密度 4。
该技能主要面向展示网站；插件采用其排版、留白、控件、对比度和状态规则，营销首页、图片墙、社交证明等要求不适用于本界面。

## 审查与改进

旧界面将查询、历史、生词和音频按钮挤在同一行；设置项连续铺开，帮助说明过多；强制浅色时部分配色仍受系统深色影响。

- 将弹窗拆成查询、导航、释义和阅读操作区域，保持动作名称与原有操作能力。
- 设置按查词方式、词典库、查询与显示、阅读外观、生词及迁移分组；较少使用的资源和排序设置可以展开。
- 标签置于输入框上方；路径自动换行；禁用无效的排序方向；操作中暂时禁用当前按钮并显示状态。
- 字体使用本机无衬线字体。蓝色用于主操作和焦点，简洁释义使用正文颜色。边框与留白区分层级。
- 共用完整的浅色和深色配色。原样模式继续保留词典沙盒内的排版、图片和字体。
- 圆角规则为弹窗 12px、常规控件 8px、批注色块 4px。只保留短暂的悬停反馈，并尊重减少动态效果的系统偏好。
- 加载、未命中和读取失败具有独立状态；状态文字可被辅助工具读取。弹窗高度不足时可以滚动到全部控件。

插件标识、既有设置键、控件 ID 和词典解析流程保持兼容；设置样式限定在插件容器，避免影响 Zotero 的其他面板。

## 预览

`npm run preview:ui` 将实际 `createCard`、`queryControls`、简洁释义渲染器、批注工具和设置组件打包为独立 HTML，输出到项目上级目录、`docs/interface-preview.html` 及 `dist` 中的版本化预览。
词条为自制示例。收藏和排序只改变当前页面的内存数据，音频是提示音；本预览不写入 Zotero 或访问本机词典。原有 `build-showcase.mjs` 演示继续提供原样词典资源渲染。

## 验证范围（2026-10-10）

- 78 项自动化检查通过；Zotero 10.0.6 的隔离配置中 33 项检查通过，包括三种词典格式、词条链接、历史、生词、笔记、本地发音、批注与清理。
- 浏览器查看浅色和深色弹窗与设置页，以及加载、未命中、错误和批注状态。
- 检查 1100×850 和 375×740 窗口；未出现页面横向溢出。240px 最大高度下可通过滚动访问发音等底部操作。
- 查询输入后使用 Tab 可到达带可见焦点的查询按钮；检查历史、固定、收藏、发音、设置数值提交及空生词列表。
- 模拟系统深色，确认显式浅色仍使用完整浅色配色、原样模式的弹窗控件随系统变化；模拟减少动态效果，按钮过渡时长为 0。
- 浅色主按钮文字对比度 5.72:1，辅助文字 5.45:1 以上；深色主按钮 8.05:1，辅助文字 7.28:1。输入边界对比度 3.08:1 以上；错误状态文字 6.48:1 以上。

旧端到端检查通过标题中的单词确认查询切换；新界面标题固定为“本地词典”，因此检查改为使用对话框的查询名称，仍验证同一查询行为。
