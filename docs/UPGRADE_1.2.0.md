# 1.2.0 · 多格式词典改进与验证

本版新增 MDX、StarDict 和 DSL 多格式支持，保留升级兼容性。历史安装包和源码文件名保持不变，见 [1.2.0 Release](https://github.com/Noahxie83/zotero-lexibridge/releases/tag/v1.2.0)。

以上为 1.2.0 发布时的迁移说明。1.2.2 起 GitHub 仓库更名为 `zotero-local-dictionary`，新安装包使用新更新地址；插件 ID 与旧设置继续兼容，见 [仓库改名与插件收录](REPOSITORY_RENAME.md)。

## 修复与改进

- 点击取词规范化软连字符、零宽字符，同时保留标点边界与命中位置判断。
- 新词典先验证后切换；坏 MDX、失败目录或失败备份不覆盖当前设置。并发切换以最新操作为准。
- MDD 使用有界块成员过滤，减少不同缺失资源反复解压同一批索引块；没有改变成功查找语义。
- 更新 source-map-js 至 1.2.2、fflate 至 0.8.3。完整依赖审计无已知告警。
- 提取词典池、查询、显示、阅读器适配、设置、生词与格式解析模块；避免每秒重写设置页。
- 先显示文字，再准备原有排版；每批 12 条，可继续加载。发音播放器由阅读器页面持有，支持外层按钮和词典链接的用户播放权限。

## 依次加入的功能

1. 英语词形还原，原词优先、有限候选、标注实际命中词。
2. 当前词典、未命中回退、联合查询；每条释义有来源，最近三部索引缓存包含当前词典。
3. 手动输入和 Ctrl/⌘+Alt+D。
4. 返回/前进、当前会话最近 40 条查询、固定弹窗。
5. 带文献与页码的生词、原文链接、CSV/Anki TSV 和 Zotero 笔记。
6. 展开查询/资源诊断、索引耗时与资源顺序、手动 MDD 移除/排序。
7. 主题、字号、弹窗尺寸、英美发音偏好和重播。
8. 有界拼写建议、分页词目浏览。
9. 多目录、优先级、可选递归、设置与生词备份、迁移时重新定位目录。

随后增加 StarDict 与 DSL，并统一产品名称。支持入口为 `.mdx`、`.ifo`、`.dsl`、`.dsl.dz`；配套文件与边界见 [格式支持](FORMAT_SUPPORT.md)，实际操作见 [使用指南](USER_GUIDE.md)。

## 验证方法

自动测试涵盖原有 MDX/MDD、资源、LZO、Speex、选区和批注回归，以及新增词形、查询模式、历史、生词、导出、迁移、并发和格式边界。格式样本由项目按规范自制，压缩流由 Node zlib 生成；Dictzip 样本还通过独立 gunzip 校验。

Windows Zotero **10.0.6** 使用新建的独立配置和数据目录运行测试：两种批注保存并重开验证、多词典、链接/历史、固定、生词/笔记、设置控件、词形、手动查询/拼写、字体、可信鼠标发音、选中文字上下文、三格式联合查询、压缩 StarDict 同义词、DSL 外置 WAV/引用、只读/分栏、原菜单和停用清理。测试不会加载日常文献库。

首次验证为 67 项自动测试、30 项 Zotero 隔离检查。发布前再次按 Standards/Spec 两路审查并整改；最新结果与复现范围见 [1.2.0 审查整改](REVIEW_FIXES_1.2.0.md)。安装包不包含测试启动脚本。

复现隔离检查：先构建，再运行 `node scripts/prepare-zotero-verification.mjs <一个新建的验证目录>`，按输出路径使用 Zotero 的 `-no-remote -profile` 参数启动。脚本拒绝已有 SQLite 文献库，超时或结束会退出隔离实例。

## 尚未加入的范围

MDX 3、密码格式、OCR、联网长句翻译、磁盘持久化索引缓存尚未加入。StarDict 资源数据库、DSL ZIP/编译词典与私有标签不保证兼容。真实 Zotero 音频验证使用 WAV，Speex 验证来自自动测试；尚未对大规模第三方词典集合做兼容性验收。
