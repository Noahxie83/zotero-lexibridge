# LexiBridge 词译桥使用指南

> 当前维护版为 1.3.1，支持覆盖升级。详见 [升级说明](UPGRADE_1.3.1.md)。

## 查询来源与独立触发开关

总开关开启后，“点击查询”和“划选查询”可分别开关；两者都关闭时仍能使用工具栏“查询”和快捷键。原生划选菜单模式继续暂停自动划选查询；关闭划选查询后，插件批注工具仍可使用。

设置中可统一启停和排序本地词典及 Google、Microsoft Edge、有道和 MyMemory 在线来源。所有在线来源默认关闭，启用说明会标明文本接收方及限制。四种服务均已有真实 Zotero 成功记录；Google 曾出现限流，后在当时网络环境恢复。接口仍可能变化或受限。有道使用网页体验接口，MyMemory 固定为英译简中并受服务配额限制。在线翻译保留原标点、最多 256 字符和 16 个词，只显示纯文本并可复制。仅在线来源可用时也可手动查询，浏览词目、拼写建议、收藏、笔记及词典音频依赖本地能力。

“当前来源”只查询所选来源；回退按用户顺序依次查询，命中即停止；联合查询按用户顺序逐项显示结果。内部词条链接只查原词典，保留全局顺序。拖动标题空白区可移动弹窗；拖动与固定独立，慢结果、手动输入、历史与内部跳转保留位置，窗口缩放只将弹窗夹紧至可见范围。

在 Zotero 10.0 系列 PDF 阅读器中点击、划选或输入文字，查询本地 MDX、StarDict 和 DSL 词典。覆盖升级保留原有设置。

从 [GitHub Releases](https://github.com/Noahxie83/zotero-lexibridge/releases) 获取安装包；1.3.1 本地构建文件为 `dist/lexibridge-1.3.1.xpi`。新版变化与验证见 [1.3.0 升级说明](UPGRADE_1.3.0.md)。

## 新增的查询与阅读操作

- 工具栏“查询”或 Ctrl/⌘+Alt+D 查询选中文字；没有选区时打开空输入框。快捷键在 PDF 阅读器中使用，输入后按 Enter 查询。
- 英语原词未命中时尝试最多 8 个常见词形候选，标明实际命中词。词组和内部链接使用原词目；可关闭词形还原。
- 查询范围选择当前来源、未命中回退或联合查询。回退和联合均按用户设置的来源顺序；结果标明来源。
- “返回”“前进”访问当前阅读会话最近 40 条查询；历史不保存到磁盘。“固定”让弹窗在滚动和点击外部时继续显示。
- “浏览词目”按输入前缀分页，每页 30 个词目；未命中时给出最多 5 个拼写建议，仅搜索有界候选。超过 12 条释义可“显示更多释义”。
- 设置中可调整主题、12–28 号字体、宽度及最大高度。英美发音偏好按资源文件名识别，无法识别时用首个发音；“重播”播放刚才的音频。文字模式不加载音频资源。
- 查询或资源失败时可展开“查询与资源诊断”查看对应来源的错误及资源路径信息；成功来源隐藏诊断。手动 MDD 可逐个移除、调整顺序。

## 生词、笔记与设置迁移

获得释义后点击“收藏”，保存原词、命中词、释义摘要、文献标题、PDF 标识、页码及可用上下文。字形信息可用时点击取词保存周边句子，划选保存选中文字；手动查询不推测原句。内部链接和切换词典保留来源上下文。同文献、同页、同词重复收藏会更新记录并保留首次日期。

“写入笔记”同时收藏并创建 Zotero 笔记：有父文献时创建子笔记，独立 PDF 附件则创建同库独立笔记。只读库不可写入。下一次查询后再次写入可能新建一篇笔记。

设置页可查看/删除生词，点击“原文”返回 PDF，并导出 CSV 或 Anki TSV。八列依次为单词、命中词、释义、上下文、文献、页码、原文链接、词典。Anki 导入时选择制表符分隔，关闭 HTML 字段解释，按自己的笔记类型映射字段。

生词最多 1000 条、约 2 MB；释义摘要保留前三条结果、最多 4000 字符。满额会提示导出或删除，不自动丢弃旧记录。备份 JSON 包含设置、生词、本地路径和文献上下文，不包含词典、资源或 PDF。导入替换备份中包含的设置和生词；目录不存在时提示重新定位，取消或遇到坏词典保留原设置。独立资源路径可能需重新选择，备份文件最大 4 MB。

## 安装与查词

1. Zotero → 工具 → 插件 → 齿轮 → 从文件安装插件，选择 `local-dictionary-1.2.0.xpi`。安装后重开 PDF，必要时重启 Zotero。覆盖升级保留原设置。
2. 设置 → 词译桥 → 选择词典目录或 `.mdx`、`.ifo`、`.dsl`、`.dsl.dz` 入口文件。StarDict 配套文件须同名、同目录。默认扫描当前层，通过“添加词典目录…”管理多个目录；可开启最多 8 层的递归扫描。最多 32 个目录、50000 个目录项。
3. 从下拉框选择当前词典。已有选择继续保留；首次按名称排序选择第一部词典。
4. 显示方式默认“词典原有排版”，读取词条实际引用的样式和资源。也可切换为“简洁文字排版”。
5. 打开有文字层的 PDF，单击正文英文单词，或用普通指针拖选完整单词/词组，松开鼠标查询。弹窗和 PDF 工具栏均可切换词典。点击发音图标/链接播放本地音频，点击词条查询链接继续查词。

划选查词默认开启，可单独关闭。独立批注工具、拖拽选区或带修饰键的操作不会触发自动查词。工具栏可开关查词，右键可添加目录。×、Esc 关闭弹窗；未固定时点击外部或滚动也会关闭。

## 划选菜单与批注

默认使用“插件查词与批注菜单”。普通指针选择文字后显示释义、8 色、高亮和下划线；先选颜色，再点击批注动作保存。自动查词和颜色选择不会创建批注。生词笔记由用户主动点击“写入笔记”创建。

插件在普通指针选文字时替代 Zotero 自带划选弹窗，避免两个菜单覆盖。关闭划选查词、选区过长或没有选择词典时，仍可显示批注工具；只读文献的批注动作禁用。

需要原菜单时，在设置中把“划选菜单”改为“Zotero 自带菜单”。此模式暂停划选自动查词，普通单击查词继续可用。关闭整个插件功能、停用或卸载后恢复自带菜单。其他高亮工具和已有批注的菜单不由插件替代。

## 划选、词组与断行连字符

PDF 把 `transformation` 分成上一行 `transfor-` 和下一行 `mation` 时，拖选两部分后松开鼠标。插件优先读取 Zotero 的 PDF 选区与字形数据，也可读取文字层选区；查询过程不改变选区，批注只在点击批注动作时创建。

| 划选文字 | 尝试的本地词目 |
| --- | --- |
| `transfor-` 换行 `mation` | `transfor-mation`、`transformation` |
| `pre-softmax` | `pre-softmax`、`presoftmax` |
| `neural network` | `neural network` |
| `state-of-the-art transfor-` 换行 `mation` | 保留全部连字符、只拼接断行处、去掉词内连字符，共至多三种写法 |

所有候选都会查询；弹窗显示各自命中情况和对应词目，相同词条合并。字形中被阅读器忽略的软连字符也作为备选处理。普通词组空格保留，不会把 `neural network` 拼成一个词。点击包含词内连字符的单词也查询两种写法。

最多查询 256 字符、16 个词，超出范围只显示批注工具。词组需要当前 MDX 收录完整词目或跳转项；本地来源查询词典释义；开启在线来源后可翻译符合上述长度限制的短句。跨行单词需划选完整两部分，普通单击不跨行扩展。扫描 PDF 仍需要 OCR 文字层。

增加、删除或替换文件后刷新全部目录。默认扫描当前层，可开启递归扫描；切换验证失败时保留原选择。多词典按查询需要建立索引，最多六部空闲索引保留在内存，使用中的索引另行保护，重启后重新建立索引。若同时使用其他查词插件，可关闭重叠触发方式。

## 通用资源和分卷

以下目录结构用于说明自动关联规则，文件名与目录可自行设置：

```text
Dictionaries/
  DictionaryA.mdx
  DictionaryA.mdd
  DictionaryA.1.mdd
  DictionaryA.2.mdd
  DictionaryA.10.mdd
  DictionaryB.mdx
  DictionaryB.mdd
  style.css
  images/icon.png
  fonts/dictionary.woff2
```

- 自动关联同名 `.mdd` 与数字编号 `.N.mdd`，按数字排序，不固定分卷数量，允许缺号。
- 名字不同或在其他目录的 MDD，通过“添加 MDD 文件 / 分卷”手动多选。可以重复添加。
- 外置资源在其他目录时，通过“选择外置资源文件夹”指定。
- 手动设置按当前 MDX 分别保存。“恢复自动关联”清除当前词典的手动资源设置。
- 查找顺序：指定外置目录 → MDX 同目录 → 自动 MDD → 手动 MDD。先找到的资源优先。
- 按词条引用读取资源，支持子目录、斜杠/反斜杠、根标记、大小写差异与百分号编码。CSS 内相对引用按该 CSS 的目录解析。
- 支持内嵌 CSS、引用 CSS、`@import`、背景图片与字体的 `url(...)`。不会把目录中所有 CSS 混合应用。

资源索引和内容按块读取，并使用有界缓存。MDD 资源按引用提取，适用于自选目录中的不同词典和分卷。

## 范围与限制

| 项目 | 当前实现 |
| --- | --- |
| MDX/MDD | 1.x、2.x；raw、zlib、LZO；2.x 的 `Encrypted=2` 索引混淆 |
| 编码 | UTF-8、UTF-16、GBK 等浏览器支持的编码；MDD 名称按 UTF-16LE 读取 |
| 查询 | 大小写配置、`@@@LINK` 跳转、重复词目与跨记录块内容 |
| 原有排版 | 保留类名、ID、自定义标签与 CSS，放入独立受限显示区域 |
| 图片/字体 | 外置文件与任意已关联 MDD 分卷；解码由 Zotero 显示引擎完成 |
| 发音 | 本地 `sound://` 及 audio 资源；内置标准 Ogg/SPX 的 Speex → WAV 解码 |

MP3、WAV、Ogg 等可解码性取决于 Zotero/系统。**SPX/Speex 解码器已内置**，无需额外程序；支持窄带、宽带、超宽带、单/双声道及每包多帧。真实 Zotero 发音测试使用自制 WAV；Speex 边界由自动测试验证，私有位流仍需按实际文件检查。

SPX 输入限额 8 MB，整个文件的累计音频最长 30 秒（包括连接的多个逻辑流），解码后 PCM 总量最多 16 MB，WASM 内存上限 16 MB。同一弹窗内重复播放复用转换结果，关闭弹窗后取消待处理解码并撤销音频 URL。技术说明见 [SPX/Speex 音频](SPEEX_AUDIO.md)。

词典内容中的 JavaScript、远程资源和外部翻译脚本不运行或加载；设置中主动启用的在线翻译服务独立工作，因此依赖脚本的切换、统计、折叠等功能可能缺失。发音链接和词条跳转由插件处理，对脚本隐藏的发音链接图片提供通用可见性适配。

暂不支持 MDX/MDD 3、密码解密、StyleSheet 反引号宏。StarDict 与 DSL 的详细支持及资源限制见 [格式说明](FORMAT_SUPPORT.md)。词形还原使用有限英语规则。

单个数据块最大 128 MB、词条 16 MB、显示 HTML 4 MB、资源 64 MB。每个弹窗最多 256 个生成资源、累计 96 MB；CSS 单文件 4 MB、累计 12 MB、导入深度 12。当前 MDX 的词目索引保存在内存；MDD 的索引和记录块分别采用有上限的缓存。大词典首次索引或跨多个分卷查找资源可能需要等待。

原有排版无法准备或创建时回退到文字排版。来源查询失败时，可展开诊断查看缺失文件名；成功来源的诊断保持隐藏，再添加相应资源包或目录。通用读取不意味着所有第三方私有格式和脚本均已兼容。

## 开发

需要 Node.js；插件运行时不需要 Node.js 或 Python。

```powershell
npm ci --ignore-scripts
npm test
npm run build
npm run pack:source
```

`npm test` 包含 MDX/MDD、LZO、资源、CSS、Speex、划选和批注适配回归用例。Zotero 持久化验证脚本只在另建的隔离配置中运行；准备方式和覆盖范围见 [1.1.2 审查整改](REVIEW_FIXES_1.1.2.md)。

- `src/mdx.js`：公共容器、解压、MDX 查询与 MDD 二进制资源读取。
- `src/resources.js`：通用分卷发现、文件夹路径与资源定位。
- `src/native-render.js`：原有 CSS、过滤后的 DOM、显示隔离、播放和资源 URL 清理。
- `src/render.js` / `src/appearance.js`：弹窗与可选文字排版。
- `src/main.js`：Zotero 生命周期、词典/资源选择与配置保存。
- `src/word-at-point.js`：PDF 点击位置取词。
- `src/selection-query.js`：PDF 划选、字形恢复和有界连字符候选生成。
- `src/selection-menu.js`：划选弹窗替代、8 色选择和 Zotero 高亮/下划线保存。
- `src/speex.js` / `src/vendor/speex/`：Ogg 分包、Speex WASM 解码、源码和许可。
- `scripts/build.mjs` / `scripts/package-source.mjs`：安装包和源码打包。
- `scripts/build-speex.mjs`：可选重新编译解码器，普通构建使用随源码提供的 WASM。
- `scripts/native-preview.mjs`：从自行指定的 MDX 生成原有排版预览，无音频，不是测试程序。
- `scripts/preview.mjs`：从导出的 HTML 生成文字排版预览。

原有排版预览用法：

```powershell
node scripts/native-preview.mjs network "path/to/dictionaries/DictionaryA.mdx"
```
