# Local Dictionary 1.2.0 · 发布前审查整改

审查日期：2026-10-10。按用户指定的 code-review 技能分别执行 Standards 与 Spec 独立审查。基准为 1.1.3（`50607be`），第一轮审查快照为 `88f30d4`；整改后复核当前工作树。规格来源为 [升级说明](UPGRADE_1.2.0.md)、[格式支持](FORMAT_SUPPORT.md)、[使用指南](USER_GUIDE.md)；工程约定参考 [资源读取设计](RESOURCE_SUPPORT.md)。

## Standards

1. **[P2，明确约定] Dictzip 清缓存后旧请求重新回填。** 原 `compressed-source.js` 只清 Map，违反资源设计“清理缓存时用代次防止旧请求重新填入已清空的缓存”。现增加代次与 pending 身份判断；门控回归覆盖旧请求完成、新请求并发去重和再次清理。
2. **[P2，明确约定] 坏生词上下文能通过备份校验。** `sourceURL:42` 原来被接受，设置页随后调用 `startsWith` 报错，违反“失败备份不覆盖当前设置”。备份与生词存储现共享字段校验，拒绝错误 URL、句子、标题、文献标识和页码。同时消除复制的不完整验证（Duplicated Code，工程判断）。
3. **[P2，工程判断] 聚合资源池没有总容量边界。** 原资源 Map 随访问词典数量增长，削弱“使用有界缓存”约定。现活动弹窗引用持有来源，关闭时释放，仅缓存三个闲置来源；逐字典资源名称和来源继续隔离。回归覆盖活动来源保护、闲置淘汰和打开期间清理。

本轴 3 项已修复并复核。第一、二项是明确约定问题，第三项是缓存约定在聚合层的工程判断；没有另行制定风格要求。

## Spec

1. **[P1] 联合查询绕过整个弹窗的资源限额。** 原每部词典单独计算 256 个 URL / 96 MB，与格式说明“每个弹窗最多 256 个生成资源、累计 96 MB”不符。现同一弹窗共享预算，来源去重仍按词典隔离；回归验证两来源同名图片、累计字节、URL 数量和重复关闭。
2. **[P2] 工具栏查询忽略选区。** 与“工具栏‘查询’或 Ctrl/⌘+Alt+D 查询选中文字”不符。工具栏和快捷键现在读取实际选区；分栏时工具栏优先有选区的视图，无选区才打开空框。
3. **[P2] 手动输入继承旧句子，快捷键选区丢失句子。** 与“划选保存选中文字；手动查询不推测原句”不符。手动输入使用当前文献/页码，句子为空；工具栏/快捷键选区保存选中文字。内部链接、历史与切换词典继续保留原查询来源。
4. **[P2] DSL 转义的资源/引用标记吞掉文字。** 与“支持……转义字符”不符。现先保护转义字符再识别标记，同时保护原文中的私用占位符。回归覆盖转义引用、声音、简写链接、波浪号及引用中的字面括号。
5. **[P2] 根目录 StarDict 配套文件与迁移失败。** 与“配套文件须同名、同目录”和重新定位约定不符。共享路径函数保留 `/` 和 Windows 驱动器根，迁移兼容根目录和结尾分隔符；回归覆盖两个系统的根目录词典与路径迁移。
6. **[P2] 部分备份清空未包含的词典配置。** 与“导入替换备份中包含的设置和生词”不符。仅外观/生词备份直接提交包含字段；影响目录的部分备份先合并现值再验证词典，省略字段继续保留，显式空值仍生效。回归验证外观导入不重建索引、目录导入保留未包含偏好。
7. **[P2，整改复核发现] 部分备份切换菜单后未立即刷新。** 快速导入新增路径最初遗漏菜单刷新，与停用后恢复原生菜单约定不符；提交后现统一刷新阅读会话菜单。

本轴 7 项已修复；原六项均为实现错误，没有发现未经授权的范围扩张。第七项为整改复核发现，随后修复。
