# 1.3.0 · LexiBridge 词译桥

本版提供 Zotero 本地查词与在线翻译。

## 新增与修复

- 新增 Google、Microsoft Edge、有道网页体验与 MyMemory 四个实验性服务，无需填写 API 密钥。默认关闭，各自说明接收方。
- 本地与在线查询来源统一启用、排序和选择；支持当前来源、依次回退、联合查询。
- 本地联合查询最多并发 2 个，在线全局最多 1 个。结果渐进显示，过期查询取消、窗口状态隔离。
- 点击与划选自动查询独立开关；总开关开启时可关闭两种自动触发，使用手动查询。
- 弹窗标题空白处可拖动；同一弹窗内的历史、内部跳转、来源切换与异步结果保持位置。固定独立控制关闭行为。
- 成功来源不显示诊断，也不占空白区域；未命中、错误、冷却仅显示对应失败来源。
- 修复关闭阅读器后，失效工具栏节点抛错阻断其他界面更新的问题。
- 名称统一为 LexiBridge · 词译桥；更新 README、展示页、封面、动图与说明。插件 ID、设置命名空间及备份格式保留。

## 升级

安装 `lexibridge-1.3.0.xpi` 覆盖旧版；若 Zotero 提示则重启。设置页入口改为“词译桥”。原词典目录、资源配置和生词保留。在线服务不会因升级自动开启。

新页面为 [词译桥展示页](https://noahxie83.github.io/zotero-lexibridge/lexibridge/)，旧首页会跳转并保留 URL 片段。GitHub 仓库及更新地址不变。

## 使用边界

在线查询最多 256 字符、16 个词，MyMemory 固定为英译简中。实验性接口可能变化、限流或不可用；开启后查询文本发送给对应提供方。没有开启在线来源时，本地查词保持离线。

本地词典的发音、收藏、笔记和浏览能力与在线纯文本译文区分。详细配置见 [使用指南](USER_GUIDE.md)。

2026-10-15，功能实现提交时产品测试 144/144 通过；独立 Node 检查 64/64，独立 Zotero 主流程 21/21。Google、Microsoft、有道和 MyMemory 均分别有真实 Zotero 成功证据。Google 曾限流，后在当前网络环境单次请求 HTTP 200、解析、显示与复制通过，成功诊断隐藏。

这些服务验证对应本版沿用的适配器实现，不代表服务长期可用。改名与展示更新后的构建、浏览器及安装检查另记于 [交付记录](DELIVERY_1.3.0.md)。
