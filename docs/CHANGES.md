# 功能与版本变更

本页汇总 LexiBridge 词译桥 0.1.0 至 1.3.1 的变化；恢复和回退步骤见 [复原教程](RESTORE.md)。

## 1.3.1 维护更新

统一仓库、展示页、下载和更新地址，精简公开名称与标识，保持设置兼容。见 [升级说明](UPGRADE_1.3.1.md)。

## 1.3.0 新增

在线服务默认关闭；四种引擎包括 Google、Microsoft Edge、有道网页体验和 MyMemory（英译简中）。点击与划选分别控制，弹窗可拖动，成功来源隐藏诊断。详细设置与边界见 [使用指南](USER_GUIDE.md)。

## 现在提供的全部功能

| 功能 | 当前行为 | 设置或恢复 |
| --- | --- | --- |
| 点击查词 | 普通指针单击 PDF 英文词语；词内连字符生成两种写法 | 独立点击开关或总开关 |
| 词典目录与格式 | 多目录、MDX、StarDict、DSL，可选递归扫描 | 选择入口文件，管理目录与顺序 |
| 多词典 | 本地词典与在线服务统一来源、当前/回退/联合查询 | 设置查询范围及优先级 |
| 查询与历史 | 手动输入、快捷键、词形、拼写建议、词目浏览、返回/前进、固定 | 按需关闭词形或调整外观 |
| 生词与笔记 | 文献上下文、本地收藏、CSV/Anki、Zotero 笔记 | 主动保存，可删除/导出/备份 |
| 外观与资源管理 | 主题、字号、尺寸、发音偏好与重播、展开诊断、MDD 顺序 | 设置中修改，下一次查询生效 |
| 划选查询 | 单词或词组；支持反向选区读取、字形分隔和文字层回退 | 可单独关闭自动查询 |
| 断行连字符 | 保留原连字符、拼接断行处、去词内连字符，至多三候选 | 不改 PDF 内容；需选完整两部分 |
| 查询结果 | 标记候选和词形命中，合并重复词条；支持内部别名 | 本地英语词形可关闭；在线支持长度限制内的短句 |
| 原有排版 | 按词条实际 HTML/CSS 引用显示，支持不同词典自身样式 | 切换“简洁文字排版” |
| 文字模式 | 词目、音标、词性、义项/例句/参照与变形行，按文字层次排版 | 切回“词典原有排版” |
| MDD 分卷 | 自动关联同名前缀与任意数字分卷，按数字排序 | 可手动多选其他名称/目录的分卷 |
| 外置资源 | CSS、导入 CSS、图片、字体、背景和音频；按引用按需读取 | 指定外置目录或“恢复自动关联” |
| 词条操作 | 发音链接播放、本地词条链接继续查询 | 不运行词典自带脚本 |
| 离线 Speex | 内置 WASM，标准 Ogg/SPX 转 WAV；无需外部程序 | 解码器随唯一安装包提供 |
| 合并菜单 | 普通指针划选时在一个弹窗提供查询、8 色、高亮、下划线 | 改为“Zotero 自带菜单” |
| 批注保存 | 通过 Zotero 接口和跨窗口数据复制保存 | 仅点保存动作时创建 |
| 清理 | 关闭/切换/停用时撤销资源 URL、取消过期请求、恢复原菜单 | 关闭整个功能或停用扩展 |
| 资源回退 | 单一来源失败继续其他目录/MDD，提示具体路径 | 补资源、刷新；旧选择在失败目录切换后保留 |
| 缓存与边界 | 有界记录/资源索引缓存、定位统计、输出限额、累计音频 30 秒 | 资源配置变化保留未变 MDX 索引 |

所有恢复方法见 [复原教程](RESTORE.md)。完整使用范围见 [使用指南](USER_GUIDE.md)，所有格式与限制仍以代码和指南为准。
