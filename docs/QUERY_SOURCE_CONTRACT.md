## Input
`queryFromText(value, source)` returns `{text, candidates, translationText, source}` or null. Capture translationText before dictionary-specific normalization/edge punctuation stripping, normalize NFC, collapse whitespace, trim, remove invisible PDF formatting characters; retain punctuation. Bound translationText to 256 characters/16 whitespace words (including entry/manual/selection/click). Existing local text, candidates and morphology remain unchanged. Empty manual input may use `{text:'',translationText:'',candidates:[],source:'manual'}`. History clones the entire input.

## Configuration and migration
Preference `sources` is a JSON string containing an ordered array (maximum 5004) of `{id,kind:'local',path,name,enabled}` or `{id,kind:'online',engineId,name,enabled}`. IDs are stable nonempty strings (max 2200), unique; path and engineId are separate, never interchangeable. Local path unique, nonempty <=2048 without NUL/newlines. Supported online engines and defaults are defined once in `src/online-engine-catalog.js`: Google, Microsoft Edge, Youdao, and MyMemory. Each default is disabled and has an enable-time disclosure naming its recipient and restrictions. `selectedSource` is a source ID. Local IDs initially `local:` + path; online defaults are `online:google`, `online:bing`, `online:youdao`, and `online:mymemory`. Relocation changes path only, never id. Unknown engines/config shapes are rejected on import. No secrets in this protocol.

`resolveSources(raw, dictionaries)` returns validated configured sources reconciled with scanned local descriptors: keep configured order, ID and enabled flags for present paths; append newly discovered dictionaries, then each missing disabled online source in catalog order. Existing source records are never copied or converted to another engine; IDs, enablement, position and selection remain intact. Missing local sources are not queried. `validateSources(value)` accepts array and returns validated copies or throws. Root persists reconciliation after successful library commits so IDs survive relocation.

`clickEnabled` defaults true; selectionEnabled remains. Old backup format/version 1 accepted, new keys optional; missing clickEnabled must not appear in validated partial settings (preserve user's current value). Backup export remains version 1 with optional sources/selectedSource/clickEnabled, validates all new fields; path relocation moves only local source paths. Changes invalidate existing query scopes.

## Capabilities and results
Local capabilities `{browse:true,suggest:true,collect:true,note:true,resources:true,audio:true}`; online all false except `{copy:true}`. Export `LOCAL_CAPABILITIES`, `ONLINE_CAPABILITIES` from query-sources.js. No online result can have dictionaryPath/html or enter MDD/native/audio paths.

Source update snapshot: `{queryId,sourceId,source,kind,capabilities,status,results,attempts,errors,warnings,stats?,elapsedMs?,retryAt?}`. Status queued/running/ready/empty/error/cancelled/cooldown. Local result `{type:'local',sourceId,dictionaryPath,dictionaryName,...existing result}`; online `{type:'online',sourceId,text,engineId,sourceLanguage?,targetLanguage?}`. The result engine must match its configured source. Every source owns separate status, diagnostic and footer nodes. Terminal errors are isolated.

## Scope, scheduler, engine
`createQueryScope()` => `{id,cancelled(),onCancel(fn):unregister,cancel()}`. Id unique across plugin calls; cancel idempotent, all callbacks composed even if one throws, late registration immediately invokes. No callback after cancellation.

`querySources(query,sources,{load,mode='single',forms=true,scope,onUpdate,translate})` => Promise `{groups,results,errors}`. `sources` is already enabled/ordered; single takes first only; fallback strictly sequential and stops on nonempty results; all uses local concurrency 2 and online plugin-global concurrency 1. Update immutable snapshots, including source status/diagnostics, in fixed configured order for final groups. onUpdate only while scope active. `load(path)` returns dictionary OR `{dictionary,release}` lease; release finally. Root supplies leases. translate(query,source,scope) => online result array. No cross-window in-flight request dedup. Preserve legacy queryDictionaries API/tests.

`createGoogleTranslator(Zotero,{now?,timeout?}={})` => `(query,source,scope)=>Promise<online results>`. One fixed endpoint https://translate.googleapis.com/translate_a/single, client=gtx, sl=auto, tl=zh-CN, dt=t, q=translationText. Request is explicitly anonymous. No rotating domains, no HTTP retries (`errorDelayMax:0`, `noRetryOnThrottle:true`), requestObserver captures XHR for abort(), timeout bounded (default 10000ms). Scope cancellation calls actual xhr.abort even when observer arrives late. Only integer HTTP 2xx proceeds to response parsing; missing status and status 0 fail closed. Transport exception text is sanitized. 429 uses Retry-After or 60s fallback, shared engine cooldown; reject with code/retryAt; no automatic resend. Strictly validate response array segments, cap text and response. Mock HTTP vs real connectivity explicitly reported; the single known public probe returned 429 with an HTML rejection response, and must not be repeated or routed through alternate endpoints.

Microsoft Edge, Youdao, and MyMemory adapters are in `src/edge-translate.js`, `src/youdao-translate.js`, and `src/mymemory-translate.js`; `src/online-translators.js` dispatches by the catalog-supported `engineId` and never retries another engine after failure. Edge is POST JSON as previously specified. Youdao POSTs form-encoded `from=auto`, `to=zh-CHS`, and the original `translationText` to `https://aidemo.youdao.com/trans`; it requires HTTP 2xx, `errorCode` zero, a bounded nonempty `translation` array, and a compatible target if returned. MyMemory sends one anonymous read-only GET to `https://api.mymemory.translated.net/get` with original text `q` and fixed `langpair=en|zh-CN`; it requires HTTP 2xx, numeric `responseStatus:200`, a nonempty bounded `responseData.translatedText`, and a non-finished quota. It never sends an email or writes translation memory. All online adapters are anonymous, do not set a User-Agent override, disable retries, truly abort observed XHRs on timeout/cancellation, and have separate provider cooldown state. They use the shared plugin-wide online concurrency lane. The three provider interfaces enforce the existing 256-character/16-word limit and do not truncate, split, or rewrite punctuation. This MyMemory direction is English-to-Simplified-Chinese only. Mock HTTP, ordinary program requests, and real Zotero requests are reported separately.

## Position module
`createPopupPosition({host,header,win,x,y,state?})` => `{position(),snapshot(),cleanup()}`. Snapshot `{mode:'auto'|'manual',left,top,x,y}`. Current iframe client coordinates only; only header blank area (target === header) starts drag, no buttons/title/inputs/selection. Pointer capture where available plus window move/up/cancel; suppress native selection during drag, restore on end. A fresh popup computes its automatic anchor once. Later position() calls, content/resource updates and resize only clamp current coordinates. A valid supplied snapshot restores left/top and mode. Manual input/history/entry/source change passes position snapshot into new card. New PDF click/selection uses fresh auto anchor. Drag independent of pinned. createCard sixth optional argument `{positionState}`; returns existing API plus `positionState()` and `addCleanup(fn)`. cleanup idempotently runs all cleanups despite errors; root never assigns current.cleanup. No reposition to original anchor after async content/resource resize.

## Coordinator integration decisions
Idle dictionary index capacity is six in the app (legacy pool default three retained for API compatibility); active leases may temporarily exceed it, and at most one retired index per path is retained during reload. All source displays share one popup resource budget. Bootstrap exposes timeout timers for HTTP watchdogs. Source selection increments the shared selection epoch; refresh preserves explicit enabled selection. A completed async source switch checks the originating popup ticket before showing results.
